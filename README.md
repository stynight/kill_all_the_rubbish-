歡迎歡迎！來此，暴打討厭的一切。

### 😆👉 [立即開打：賽博打小人](https://stynight.github.io/kill_all_the_rubbish-/)

一個在瀏覽器裡就能玩的驚蟄打小人，不用怕沒時間、鼻敏感、距離遠~！
上香拜神、寫小人或者貼相、七件兵器輪流招呼、阿婆代打、祭白虎、化寶、擲筊祈福，一條龍走完。不用登入，不用安裝。

## 玩法

1. **奉神上香**：揀觀音娘娘、土地公公或者財神爺，上三炷香，拜三拜。
2. **寫小人**：單打寫一個名，或者群攻一次排十二個。不知道是誰就寫「小人」。也可以貼相，貼在頭上或者貼滿全身。
3. **打小人**：膠拖鞋、舊皮鞋、高踭鞋、木屐、雞毛掃、平底鑊任揀，打多了會儲滿春雷，放出雷公鎚。按住不放可以一路連打，打累了就叫阿婆代打（慢、中、快、癲四檔）。
4. **祭白虎**：把肥豬肉拖到白虎嘴邊，再撒芝麻綠豆，白虎食飽就不會咬人。
5. **化寶**：打爛的小人紙、白虎紙、衣紙、金銀紙全部燒掉。
6. **擲筊祈福**：擲出聖杯就完成。連續兩次不是聖杯，第三次一定是。

## 小提示

- 第一次按畫面之後才會有聲音。
- 鼻敏感的話，可以開「鼻敏感模式」，香火煙會淡很多。
- 頁頂會倒數下一次驚蟄（香港時間）。驚蟄當日春雷儲力加倍。
- 名字和相片只在你自己的瀏覽器裡處理，不會上傳到任何地方，關掉網頁就沒有了。
- 手機可以「加到主畫面」，打開過一次之後，沒有網絡也能打。
- 電腦上可以用數字鍵 1 至 7 換兵器，空白鍵出手。

## 在自己電腦玩

下載這個 repo，用瀏覽器打開 `index.html` 就可以。所有東西都在這一個檔案裡。

## 製作過程

起因是某天頭疼、覺得概率都在針對自己，跟 Claude 聊著聊著就說想打小人。於是一邊聊一邊加：先有神壇和香火，再有七件兵器和阿婆代打，後來加了貼相、離線玩、擲筊保底。程式由 Claude 編寫，點子、測試和挑毛病由作者負責，從第一句「頭疼」到網站上線，大約一個晚上。

作者試玩後的感想：情緒上來的時候打一下，是真的爽。
